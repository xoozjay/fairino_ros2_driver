# FAIRINO Robot ROS 2 Driver

[中文文档](README.zh_CN.md)

This project provides a hardware driver integration for FAIRINO robots with [ros2_control](https://control.ros.org/jazzy/index.html), as well as [MoveIt 2](https://moveit.picknik.ai/main/index.html) configuration support.

This project was developed for ROS 2 Jazzy. You may adapt it to other ROS 2 distributions as needed.  
This project was tested with the FR5 v6. Adaptation may be required if issues occur with other robot models.

An [official implementation](https://github.com/FAIR-INNOVATION/frcobot_ros2) is available, but its functionality is very limited.
