# 法奥协作机器人 D-H 参数

> 整理日期：2026-09-01  
> 主要来源：[法奥机器人简要介绍——DH 参数表](https://fairino-doc-zhs.readthedocs.io/latest/CobotsManual/robot_brief_introduction.html#id5) 及该页面提供的官方 D-H 参数表。

## 约定

- 采用官方表格的参数含义：`θ`、`d`、`a`、`α`。
- 本文件使用官方下载表中的 SI 单位：`θ`、`α` 使用 **rad**，`d`、`a` 使用 **m**。
- 官方表中所有关节的零位参数 `θ` 均为 `0`；实际关节角由控制器/模型的关节变量代入。
- 按经典 D-H 形式使用单节变换：

  ```text
  A_i = Rz(θ_i) · Tz(d_i) · Tx(a_i) · Rx(α_i)
  ```

- 这些是厂商名义运动学参数，不等同于 ROS URDF 中的 link frame 变换；将参数用于 URDF、TF 或真实机器人 TCP 时，还需确认坐标系约定和零位定义。
